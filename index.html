🏎️ SYSTEM OVERVIEW

F1 Manager 2026 is an industrial-grade simulation placing the user at the helm of a Formula 1 team. Managing constraints scales directly across the competitive grid, simulating accurate environments from historic independent constructs like Minardi to high-efficiency corporate entities like Siemens.

Users execute critical infrastructure updates, source dynamic engine provider contracts, balance fiscal limits, and architect a customized Team Principal profile engineered to adapt to real-time strategic anomalies.

💻 ARCHITECTURE & CORE SOFTWARE STACK

Designed with professional modular conventions optimized for evaluation environments similar to frameworks used by Kros and Siemens:

  • Frontend Layer: Built on Windows Presentation Foundation (WPF) with full data-binding mechanics utilizing ObservableCollection.
  • Simulation & Logic Backend: Object-Oriented C# architecture relying on a decoupled Database.Instance Singleton pattern.
  • AI Orchestration Pipeline: Advanced REST API integration using HttpClient to process asynchronous payloads targeting the Groq platform (Llama 3.3).
  • Environment Handling: Secure run-time security using DotNetEnv for token injection.
